# Intent: 담당자의 업무 요청을 골라서 조회
Author: 실험 요청자 (합성 사례 F01). Status: draft.

## Problem
작은 팀이 로컬 CLI로 업무 요청을 확인한다. 여러 담당자의 요청이 섞여 있어 특정 담당자의 일을
볼 때마다 전체 목록에서 눈으로 고르고 있다.

## Proposed outcome
담당자 ID로 목록을 좁혀 그 담당자의 요청을 확인하고 싶다. 전체 목록에서 직접 골라내는 일을 줄인다.

## Affected users and systems
업무 요청을 확인하는 작은 팀, tracker.py의 list 명령과 requests.json.
현재 Python 3.9 이상 표준 라이브러리만 사용하며 외부 서비스·계정·네트워크는 없다.

## Constraints
- 기존 list/show/complete 명령과 JSON 필드를 유지한다. 조회는 파일을 변경하지 않는다.
- 업무 코드는 2~4파일 이내의 작은 변경이며 시험·문서는 별도다.

## Open questions
- 완료된 요청도 포함하고 현재 파일 순서를 유지할지 요청자에게 확인한다.
- 미배정 요청도 선택해야 하는지, 담당자가 없을 때 어떤 결과를 기대하는지 요청자에게 확인한다.
- 담당자 ID의 일치 방식과 원하는 명령 사용법을 요청자에게 확인한다.
