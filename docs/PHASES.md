# PHASES.md — 의도적 미구현 원장

빠짐이 「보이지 않는 결손」이 아니라 「의도적 미구현」임을 이름으로 남긴다. 이 표에 있는
항목은 지금 이 레포가 안 하는 일이고, **승격 조건**이 참이 되면 그 항목은 티켓이 된다 —
말 없이 다음 웨이브에 슬쩍 들어오지 않는다. 원문은 설계안(`docs/DESIGN.md`) §10.

| 항목 | 레슨 | 왜 지금 안 하나 | 승격 조건 |
|---|---|---|---|
| intent merge → spec PR 자동 생성 job | 3 | 손으로 반복되는 패턴이 아직 3회 미만이라 자동화 비용을 정당화 못 함 | 손으로 3회 반복될 때 |
| Claude Design 목업 → Code 핸드오프 | 3 | 이 샘플에 UI 컴포넌트가 없어 핸드오프할 대상이 없음 | UI 있는 예제가 생길 때 |
| auto mode · worktree 병렬 세션 | 4·7 | 1인 레포라 동시 작업자가 없어 병렬 조율 장치가 필요 없음 | 동시 작업자 2인 이상 |
| 스킬 트리거 시험(모델 발화) | 6 | 모델이 스킬을 실제로 호출했는지는 결정론 스크립트로 못 재고, 반복 측정할 evals 예산(키)이 없음 | evals 가 키를 얻을 때 |
