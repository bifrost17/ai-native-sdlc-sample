# S3 · compliance — 결정

**날짜(UTC)** 2026-09-10 · **레인** `lane/S3-compliance` · **정본** `policies/compliance.md` v0 (draft, 오너 서명 대기)

## 결정
`policies/compliance.md` 의 C1~C7 을 덮는 스킬을 **직접 설계한다 — 둘로.**
공개 스킬 18건 중 **채택 0건.**

| | 무엇 | 조항 | 트리거 |
|---|---|---|---|
| 설계 | `skills/claim-data-compliance/` | C1 · C2 · C3 · C6 · C7 | 3/3 |
| 설계 | `skills/claim-notice-compliance/` | C4 · C5 | 3/3 |
| 보류 | `pii-scrubber` · `audit-logging` · `consent-record-keeping` · `data-privacy-compliance` | — | 도너로만 보관 |
| 기각 | 나머지 14건(그중 1건은 라이선스 GPL-3.0) | — | — |

집합 충돌 시험 1회 통과(네 스킬 동시 적용, 모순 없음). 7개 조항 전부 「덮음」 — 빈 조항 없음.

## 왜
근거는 `docs/research/compliance/README.md`(결론·구멍·오너 질문), `candidates.md`(18건 판정과 이유),
`coverage.md`(조항 × 스킬 · 겹침 · 모순 · 빈칸), `trigger-tests.md`(로드 6/6 + 집합 1회).

1. **채택 0 의 이유는 형식이 아니라 내용이다.** 18건 모두 Agent Skill 형식은 충족한다. 그런데
   **3년 보존(C6)을 말하는 파일이 0건**이고 대신 6년·1년·6개월 같은 다른 숫자가 「법적 요구」라는
   단정과 함께 들어온다. 이메일/SMS 스킬은 사실상 마케팅 스킬이라 **「거래성 메시지는 동의가 필요 없다」**
   는 C4 와 정반대 결론을 가르친다. C7(대리 조회 + 본인확인 기록)은 **덮는 스킬이 아예 없고**,
   `gdpr-compliant` 는 오히려 대리 조회 경로를 403 으로 막는다. 자세한 모순 표는 `coverage.md`.
2. **좋은 점은 가져왔다.** 허용목록의 fail-closed 논증(`pii-scrubber`), 누출 경로 3종을 나눠 짚는 짜임
   (`healthcare-phi-compliance`), 조회(read)를 1급 감사 대상으로 두고 역할과 ID 를 나누는 필드 골격
   (`audit-logging`), 전제 레코드 없으면 상류 호출 **전에** 거부하는 형태(`purpose-based-access`).
   어디서 무엇을 가져왔고 왜 그대로는 안 되는지는 각 `PROVENANCE.md` 에 후보별로 적었다.
   **기각한 후보가 내용을 만들기도 했다** — `claim-notice-compliance` 의 「마케팅 관행을 가져오지 않는다」
   문단은 후보 4종이 실제로 그것을 가르치는 것을 읽고 쓴 것이다.
3. **둘로 나눈 이유**는 자리와 어휘가 다르기 때문이다(데이터·로그·이력 / 고객에게 보내는 메시지).
   대신 경계를 본문에 못박아 C6 문면은 한 곳에만 두었다 — 두 곳에 적으면 개정 때 갈라진다.
4. **S5 영역은 다시 쓰지 않았다.** C3 은 `secure-api-review` 4항과 겹치므로 **「어긋나면 그쪽이 정본」**
   이라고 본문에 적고, 이 스킬이 더하는 것은 대상이 audit 이벤트까지 넓다는 한 가지뿐임을 밝혔다.
   그 스킬의 본문은 플레이북 예시 축자라 손대지 않는다.

## 이 결정이 서 있는 가정
- 정본이 **서명 전 v0** 다. 조항 문면이 바뀌면 두 스킬의 인용 블록과 `coverage.md` 를 함께 고친다.
- 스킬은 **권고적 통제**다(L6). C1·C3·C4 는 어기면 되돌릴 수 없는데 뒤를 받치는 훅·리뷰 패스가 아직 없다.
- 오너에게 묻는 8가지가 열려 있다(README). 스킬은 그 자리에서 답을 지어내지 않고 「덜 싣는 쪽」을
  기본값으로 두고 spec 의 Flagged concerns 로 올리게 했다.

## 하지 않은 것
- `policies/*.md` 를 고치지 않았다. 모호한 자리는 결정하지 않고 오너 질문으로 넘겼다.
- 다른 세션의 폴더와 `docs/research/README.md`(공용 색인)를 건드리지 않았다 — 색인은 부모가 묶는다.
- 플러그인 배치(`--plugin-dir`)로는 시험하지 않았다 — 확인 못 함.
