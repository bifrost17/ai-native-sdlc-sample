# 단일 템플릿과 Codex·Claude Code 스킬 제공

2026-09-15. 사용자가 TDD 선택형을 유일한 템플릿으로 삼고 강제형을 삭제하도록 요청했다.
이 결정은 [2026-09-12의 두 배포판 구조](template-variants.md)를 대체한다.

현재 채택 정본은 `main`의 `tdd-optional/project/` 하나다. 기존 사용자 경로와 패키지 식별자를
유지하기 위해 폴더 이름은 바꾸지 않는다. 작업별로 TDD·구현 후 테스트·기존 테스트·혼합을 선택하고
이유와 검증을 plan에 담는다. 요구·설계·계획 추적성과 영향 문서 갱신, 독립 기대, 사람의 결정은 유지한다.

`tdd-first/`와 해당 설치 항목은 삭제한다. 과거 intent·실험·리뷰·검증 자료는 당시 사실로 보존한다.
폐기 직전 소스가 필요하면 이 저장소에서 다음과 같이 확인한다.

```bash
git show b9af49a:tdd-first/README.md
git ls-tree -r --name-only b9af49a -- tdd-first
```

단일 배포 전환 당시 패키지는 0.1.8이었다. 현재 0.1.9도 두 도구에 같은 작성 스킬 3개·팀 스킬 13개·검토 기준을 제공한다.
[Claude Code](../../tdd-optional/org-skills/claude/README.md)는 프로젝트 작성 폴더와 팀 플러그인 설치를
구분하고, [Codex](../../tdd-optional/org-skills/codex/README.md)는 같은 원본 폴더에 도구별 패치를 적용한다.
명시 사용 정책, 동반 자료, 프로젝트 정책 우선과 갱신 시 기존 수정 보존을 함께 안내한다.
도구별 경로·호출 이름·검증자 설정은 각 도구 방식에 맞춘다. 기존 OpenCode 어댑터는 보존한다.

제품에 새 installer 프로그램·승인 단계·의미 검사기를 추가하지 않는다. 기본형 삭제는 기존 제품이나
개인 설치를 자동 삭제하는 작업이 아니다. 구판을 사용하는 팀은 현재 정책·설치 출처를 확인하고
필요한 변경분을 병합한다. 기존 TDD 작업을 중간에 자동으로 다른 방식으로 바꾸지 않는다.

[구현 계획과 검증 범위](../../intent/0027-single-template-skill-parity/plan.md)에 작업·근거를 기록한다.
설치 자료 준비·정적 검증을 전체 SDLC나 실제 모델의 자연 선택 성공으로 확대하지 않는다.
