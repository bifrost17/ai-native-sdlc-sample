# 0015 — 작은 사용 템플릿의 대화형 개발 검증

**통과:** Codex root가 사람 역할로 검토·수정·인도까지 확인하고, 주요 흐름이 대체로 잘 작동하며
중요한 회귀가 남지 않았다고 판단했다. 두 개선을 완벽한 가이드 재현의 주장으로 확대하지 않는다.

## 무엇을 보완했는가

1. **중요한 사용자 결정을 다음 단계까지 유지** — V2-09·V2-11·V3-09. 가정과 결정 구분,
   질문이나 리뷰로 확인한 동작을 인계 문서에 남긴다는 짧은 안내.
2. **실행할 수 있는 계획과 실제 변경의 연결** — V4-08·V4-11. 핵심 결정·참조·검증만 충분히
   기록하고 중요한 이탈은 이유와 함께 반영한다는 안내. 수락 방식은 프로젝트 정책에서 정한다.

원래 기준 `codex/use-template@a2bbfe1`은 보존했다. 실행 후보 `de1b1b7`은 네 문서의 안내만
바꿨으며 전체 변경은 17줄 추가·16줄 삭제다. 후속 정적 리뷰의 `15ab8a6`은 정책 표 제목 두 곳을
같은 검토·수락 용어로 맞춘다. **현재 권장 후보는 `codex/use-template-0015@15ab8a6`**, 파일 16개다.
새 집행 스크립트나 필수 스킬은 없다. 15ab8a6의 제목 변경은 별도 정적 리뷰로 확인했으며 실제
Claude 실행의 기준 de1b1b7과 섞어 쓰지 않는다. 이번 기록은 두 버전의 A/B 효과 비교가 아니다.

중복 시험을 피한 선택은 수용하고 실제 재사용한 시험을 계획에 반영하게 했다. 동료에게 필요한
사용 안내를 추가하면서 plan도 같은 build 커밋에 갱신했다. README에 남아 있던 ‘제품 코드·시험
없음’은 한 차례 더 피드백해 정정했다. 완성본 한 번을 받아 통과시킨 실험이 아니다.

AGENT가 complete 예시 확인 중 원래 fixture를 바꾼 실수도 있었다. 스스로 보고하고 복구했으며
HUMAN이 원본 커밋과 바이트 일치를 확인했다. 이후 새 디렉터리에서 인도를 검증했다. 이처럼
수정된 편차를 숨기지 않되, 직접 대응 가능한 사내 프로그램에 강제 장치를 늘리는 근거로 삼지 않는다.

## 전체 흐름 회귀와 제외 범위

챕터 2~13의 전체 연결은 실험 브랜치 `EXPERIMENT.md`의 12행 범위 표로 확인했다.
이번에 바뀐 결정·계획과 인접 단계는 다시 읽었고, 고정 설명·양식의 영향 없는 근거는 재사용했다.
관련 설정·데이터·모델 조건이 바뀌거나 새 실패가 생기면 재평가한다. 모든 문단을 별도 LLM에
반복 제출하거나 기존 제작 저장소의 139개 ‘충실’을 사용판에 승계하지 않았다.

- 제품 기존·신규 시험 **5/5**, HUMAN의 독립 동작 **4/4**, 새 디렉터리 인도 명령 **7/7** 통과.
- 기존 시험·도우미 함수 불변. 새 시험을 옛 구현에 실행하면 신규 2개만 실패하는 민감도 확인.
  이것은 구현 후 대조이며 선행 red 단계로 주장하지 않는다.
- 별도 Sol/high 리뷰에서 중요한 Bugs/Security/Policy-scope 발견 없음. Astra/ultra의 대화 없는
  문서 검토도 계획이 충분하다고 판단. 대화를 못 본 별도 구현은 실행하지 않았으므로 V4-08은 부분 유지.
- 제작 전체 `make check`: **81 tests, 1 skipped**, hooks 28/0, evals 8/0, managed-settings PASS.
  skip은 이 Mac에서 대소문자를 구분하는 파일시스템 대조 1건이다.
- 팀 플러그인은 실제 init에서 0개. 내장 스킬 18개는 제공됐으나 Skill 호출과 자체 예시 읽기는
  0회였다. 이 작은 기본 조건의 직접 조사·시험을 평가했고, 팀 스킬 적용의 성공을 주장하지 않는다.
- 실제 조직 PR·권한 분리·호스티드 CI·운영 배포·장기 지표는 미관측이다. 후속 다양한 개발건은
  같은 버전·seed 원칙으로 별도 실행한다. B01/C01은 데이터만 준비했고 전체 실행은 아직 없다.

## 보존 위치

실험 통합·단계 브랜치 6개를 제작 저장소의 로컬 refs에도 가져와 보존했다. 제품·대화 원문은
제작 main tree에 합치지 않았다. 예: `git show codex/experiment-2026-09-10-f01-r01:EXPERIMENT.md`.
`run-summary.json`은 모델·세션·시간·비용·파일 해시, `raw/`는 공개 대화·정제 도구 기록과 검증 출력이다.
계정 이메일은 마스킹했고 숨겨진 추론과 HUMAN 비공개 원본은 제외했다.
로컬 실행 폴더는 `../ai-native-sdlc-experiments/f01-r01`, HUMAN 전용 보관은 그 옆 `human-f01-r01`이다.

지침·데이터·페르소나와 이 기록은 main에 두며, 주석에는 이번에 통과한 관측 범위만 추가한다.
