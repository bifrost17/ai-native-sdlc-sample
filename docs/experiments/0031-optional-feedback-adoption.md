# 0031 — 선택형 팀 스킬 채택 연결의 최소 보완과 부분 재실험

2026-09-12. 0030 완료 뒤 사용자가 북극성에 따른 보완–실험 루프를 요청했다. 이 계획은 변경·실행 전에
기록한다. 목표는 사람과 함께 주요 지침을 대체로 따르는 수준이며 완전 자동 통제가 아니다.

## 발견과 선택

[0030](0030-optional-sonnet.md)은 후속 JSON의 spec→plan→구현→시험·같은 커밋을 지켰다. 그러나
최신 변경 뒤 독립 검토를 두 번 누락했고 sdlc-feedback 본문은 한 번도 로드하지 않았다. 팀 패키지는
설명으로 스킬 사용을 판단한다고 안내하지만 **채택한 팀의 프로젝트 진입 지침에 연결하는 예시가 없다**.
이는 호출 실패의 유일한 원인이라는 주장이 아니라 작게 보완·확인할 수 있는 전달 공백이다.

북극성 V4-11은 구현에서 벗어난 plan을 같은 커밋에 갱신하며 동기화 hook은 고려 사항으로 둔다.
V7-08/09의 verifier 예시는 완료 전에 실제 동작을 확인해 보고하고 수정·승인을 맡지 않는다.
0030의 좋은 문서 동기화는 유지하고 이 이벤트 연결만 명확히 한다. 기록 오판마다 새 규칙을 추가하거나
검토자 오류를 없애려고 시도하지 않는다.

## 변경 범위와 리뷰

- 선택형 팀 패키지에 **명시적으로 채택한 팀만** 제품 CLAUDE.md에 넣을 짧은 안내 예시를 제공한다.
  계획 구현/실질 변경에서 sdlc-feedback의 관련 절을 읽고 완료 전에 최신 범위를 검토한다는 연결이다.
  현황 질문·단순 산문 수정에는 실행하지 않으며 기존 동등 검토를 중복 실행하지 않는다.
- Claude/OpenCode 설치 안내에서 이 선택 예시와 실제 이름/경로를 연결한다. 순수 `project/`에는
  특정 팀 스킬 이름·활성 파일을 넣지 않는다. 기존 스킬 본문과 verifier 기준·TDD 선택 정책도 유지한다.
- 패키지/marketplace 판을0.1.3으로 맞추고 완결 복사·strict validation·OpenCode patch 적용을 확인한다.
  새 훅·프로그램·의미 검사·상태 양식·사전 승인 단계·모델 상향은 만들지 않는다.
- root가 작성하고 Sol high 독립 리뷰가 범위·설치 연결·실험 교란을 확인한다. 정적 검증 후 실제
  developer는 Sonnet/medium, 실험 사본의 native도 Sonnet/medium을 유지한다.

## 고정 재실험

부분 실험이다. 0030의 JSON 전 제품 `8031dff`까지만 새 디렉터리에 복제하고 미래 JSON/정정 객체가
없음을 확인한다. 새 순수 사용판과 선택 설치 seed·변경 브랜치를 보존한다. 팀0.1.3과 새 채택 안내를
적용하며 기존 텍스트 summary를 HUMAN이 기준으로 수락한다. 전역 설치·원격 push는 하지 않는다.

새 Claude 세션에 동일 D7 업무 계약만 요청한다. 프롬프트에서 문서명·스킬명·검토 시점을 상기하지
않는다. 새 세션이어도 제품 기록에 이전 검토가 있으므로 완전 무교육/인과 대조로 해석하지 않는다.
첫 개발 호출부터 **최대3회/30분**: 첫 구현 제출, 필요시 실제 발견 복구, 짧은 상태 질문 또는 필요한
검증 재확인 범위다. 추가 호출로 원래 실패를 지우지 않는다. 같은 소스 재실행이 더 필요하면 이유와
별도 시도를 먼저 기록한다.

중요 기준은 영향 spec/plan의 선행 갱신·관련 구현의 같은 커밋, 현재 요구/선택 방식·독립 기대,
채택 스킬의 실제 본문 사용·최신 native 검토/부모 대기, 전체 기존 제품 회귀·통합·새 복제본이다.
고정 문서 구조/원문은 기존 정적 근거를 재사용한다. 관측은0030과 같은 독립 observer로 수행하며
HUMAN-only oracle은 제품에 전달하지 않는다. 단계별 입력·raw 사건·실패·보완·refs·bundle을 저장한다.

핵심 문서/동작에 중요한 실패가 없고 완료 인계가 보완된 사례를 관측하면 종료한다. 사소한 서술 오류나
관계없는 모든 스킬 사용을 완벽하게 맞추려고 반복하지 않는다. 중요한 실패가 남으면 사람 복구와
자연 수행을 구별하고, 예산 내 최소 수정만 한 뒤 미해결 범위를 남긴다.
