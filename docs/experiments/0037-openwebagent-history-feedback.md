# 0037 — 실사용 이력에 따른 작성·통합 지침 비교

Status: 사용자 지시로 중단. 준비와 부분 수행을 보존하며 전체 통과나 개선 효과를 판정하지 않는다.

2026-10-03 사용자가 조사·보완안까지만 진행하고 실험은 별도 지시 후 수행하도록 범위를 변경했다.
진행 중인 b-before/02와 b-after/01 Codex 프로세스를 SIGTERM으로 중단하고 원문/미커밋을 남겼다.
Claude 최초 호출은 조직 구독 차단으로, OpenCode의 두 대체 호출은 공급자의 PAT 불지원 오류로 종료됐다.
가용 모델 목록이나 auth-ready 사전 확인은 실제 호출 가능성을 증명하지 못했다.
c-transfer는 설치/fixture 준비만 했으며 모델 호출은 0회다. 완료된 전후 쌍·전이·독립 오라클 평가가 없으므로
어느 템플릿도 개발 실험 통과라고 하지 않는다. 새로운 실험 시작·재개는 사용자 지시를 받는다.

## 입력과 범위

[전수 조사](../research/openwebagent-template-history/README.md)에서 고른 실제 경계 문제를 작은 제품으로
구성한다. A는 0027의 앱 전역 키 처리/실제 설정 저장, B는 0018의 두 소비자 ACK와 최종 완료 구분이다.
원제품 전체의 재현이나 과거 모델/OS 비용 비교가 아니다. 초기 pilot 밖의 0027을 포함한다.
기준판은 제작 ad98adec의 0.1.8, 수정판은 0.1.9와 최초 WIP5+이번 변경 묶음이다. 개별 문구 효과는 입증하지 않는다.

기본 실행은 A Claude Sonnet/medium 전후 2회, B Codex gpt-6-sol/medium 전후 2회,
다른 도구 Codex의 A 전이 1회다. 역사에서 도구 계열은 확인되지만 전체 모델/추론 수준은 미확인이며
현재 가용 모델로 대체한다. 실제 요청 모델과 응답/세션에서 관측한 모델은 별도로 기록한다.

각 실행은 독립 template 설치판→동일 fixture 시작판→별도 작업 브랜치를 보존한다. 같은 쌍의 첫
업무 입력은 같은 파일·hash를 사용한다. root가 초안을 보고 구현을 요청하고 실제 결과를 받은 뒤
업무 변경을 전달한다. 고정 후속 대본으로 모든 답을 지시하지 않는다. 새 세션에는 최신 문서와
선언된 참조/제품 판을 넘겨 부족한 검증과 인계를 이어가게 한다. 총 실행 5회/최대9회, 수정 최대2차,
각 실행의 모든 대화/인계 호출을 합쳐30분 이내다. 모델 호출 수와 실행 수는 다르다.

## 판별과 한계

설계의 실제 검증 경계, 첫 통합 시점, 앱 셸/상태·시각 기준, 후속 spec/plan 갱신과 관련 커밋,
과거 계약 대조, 현재 상태/PR본문의 대상판·미완료, 인접 회귀를 평가한다. 실제 HTTP/SQLite와
Headless Chrome 오라클은 실행 전에 별도 위치에서 고정했다. 에이전트 제품에 정답표를 복사하지 않는다.
기준판도 잘 수행하면 추가 개선 효과 미관측으로 적는다. 사람의 수정 유도와 초기 자발적 수행은 구분한다.

설치 원본·manifest·prompt·raw CLI JSONL·stderr·model/effort·Git·시험·스크린샷·평가는
`.local/research/openwebagent-template-history/20261003/runtime/`에 보존한다. 원문은 비공개다.
Claude는 기존 CLI 인증과 세션 한정 --plugin-dir, Codex는 기존 CLI 인증을 사용한다.
전역 설정·스킬은 변경하지 않지만 CLI 기본 경로에 세션 기록이 생길 수 있다. 설치된 파일과 실제
읽기/활용은 구분한다. 계정/운영 데이터·원제품은 사용하지 않는다. PR은 로컬 본문 초안으로 평가하며
실제 GitHub PR 생성·통합 승인·운영 배포를 주장하지 않는다.
