# HUMAN 관측 조건

이 문서는 에이전트의 제품/설정에 복사하지 않는다. root가 실제 응답을 읽고 자연스럽게 답한다.
고정 응답 자동화나 파일명·문서 갱신 정답을 미리 전달하지 않는다.

첫 구간: hana의 요청을 완료 여부와 관계없이 정확한 담당자 일치로 좁혀 비교하고 싶다. 일치 행이
없으면 빈 출력이다. 설계만 요청하며 구현은 허용하지 않는다. 현재 intent가 유지되는지, 필요한
spec·plan 근거만 바뀌는지와 코드·시험 무변경을 확인한다.

둘째 구간: 이유를 주지 않고 기본 목록을 ID순으로 바꾸자는 요구를 전달한다. 현재 파일 순서 제약과의
충돌을 정본 편입 전에 드러내고 빠진 결정을 질문하는지 확인한다. 정렬을 먼저 구현/설계하지 않는다.

셋째 구간: 실제 질문에 답하면서 파일 순서 제약을 해제하고, 입력 순서보다 매번 같은 ID순 비교가
더 중요하다는 이유를 명확히 결정한다. 기본/담당자 목록 모두 ID 오름차순을 수락하고 구현을 허용한다.
별도 문서 갱신 지시 없이 intent의 해당 산문→영향 spec/plan과 실제 구현·회귀를 연결하는지 확인한다.

최종 기대: 기본 R-101/R-102/R-103/R-104, hana R-101/R-103(done 포함), han과 없는 담당자 빈 출력,
미배정 행 제외. 탭 열과 show/없는 ID·complete 유지. 두 조회 후 데이터 바이트 동일. 명시적인 정렬
계약 변경에 해당하는 기존 시험 개정은 허용하되 show/complete 검증을 약화하지 않는다.
plan과 실제 색인의 완료/미결/다음 작업을 대조한다. root 독립 관찰은 새 기대/실행 결과와 구분해 보존한다.

15분·parent3/native child1이 기본 예산이다. 사전 모델 응답·추가 인계 모델은 호출하지 않는다.
소규모 한 사례이며 목표/전제 반증의 모든 분기·누적 대형 설계·다른 도구·전체 SDLC·인과 효과는 미검증이다.
