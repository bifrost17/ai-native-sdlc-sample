# 0039 제품 시작 조건

로컬 JSON 요청 목록 CLI의 현재 기능은 `list`, `show ID`, `complete ID`다. 실제 시작 코드와
시험은 datasets/v1/baseline/tracker.py·test_tracker.py에서 복사한다. 시험은 제품의 `tests/`에 둔다.
요청 데이터는 같은 v1/F01 네 행을 R-102, R-103, R-101, R-104 순서로 재배열한 파생 fixture다.
기존 완료 변경 시험의 첫 대상이 open인 조건을 보존하면서 ID 정렬 구현 여부를 관측할 수 있다.
원본 코드·시험·v1 fixture는 수정하지 않는다. 설치판과 각 입력의 해시를 실행 manifest에 남긴다.

시작 의도는 여러 요청의 담당자·상태를 빠르게 비교하는 것이다. 기존 탭 열과 세 명령을 유지하고,
조회는 데이터를 쓰지 않으며 목록의 파일 순서를 유지한다. 새 기능은 초기 정본에 미리 넣지 않는다.
HUMAN(root, Codex simulated)이 역할·단계 수락과 실제 입력의 사실을 확인한다.

검증은 제품의 기존 unittest와 실제 CLI 출력·종료 코드·파일 바이트로 수행한다. 공개 입력은 합성
네 행뿐이다. 원제품·실데이터·UI·네트워크 서비스·원격 PR/CI·배포는 이번 제품에 없다.
