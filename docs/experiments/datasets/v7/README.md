# F05 — 요청 대장 공유 서비스

v7.0.0 / seed103. 0026의 작은 CLI 옵션 추가보다 큰 단일 개발건이다. 기존 JSON CLI를 보존하고
SQLite 초기 가져오기·동시 변경을 고려한 HTTP API·CSV 소비자를 추가한다. 3~4 PR 정도의 공통
기반과 소비자 분할, 새 문맥 인계, 구현 중 상태 계약 변경, 통합·fresh 인도를 관측한다.

공개 입력은 `F05-team-service/public.json`, `requests.json`과 v1의 변경하지 않은
`baseline/tracker.py`, `baseline/test_tracker.py`다. HUMAN 결정은 `human.json`이며 진행 AGENT에게
복사하지 않는다. 입력의 표현은 대화에 맞춰 바꾸되 정해진 후속 대본을 재생하지 않는다.
완료 재열기 D7은 최초 API 구현을 실제로 읽기 전에는 공개하지 않는다.

사용판의 양식·교육 예시는 그대로 제공한다. 해법의 구조를 가르치는 예시가 있어 무힌트 시험은
아니며, 기존 F04 데이터·완성 코드·대화는 전달하지 않는다. 스킬의 예시 정책보다 실제 프로젝트
정책의 합성 로컬 범위를 우선한다. 전체 실험·판정은 [0027 기록](../../0027-muse-larger.md)에 둔다.
