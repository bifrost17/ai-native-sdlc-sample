# Intent: 사내 집계 결과를 중복 발행 없이 전달
Author: 합성 실험의 HUMAN 제품 오너. Status: draft.

## Problem
업무 담당자가 합계 계산을 다시 요청하거나 작업 프로세스가 재시작하면 같은 집계 결과가 중복 발행될 수 있다.
응답이 끊겼다고 작업이 취소됐다고 오인하지 않도록 현재 상태도 조회하고 싶다.

## Proposed outcome
한 사내 업무 공간에서 작은 정수 목록의 합계를 계산하고, 기존 사내 결과 보관 서비스에 요청당 한 결과를 발행한다.
같은 요청은 재조회·재전송해도 같은 결과로 이어지며 독립 프로세스 재시작 뒤에도 이를 유지한다.

## Affected users and systems
업무 담당자, 요청 조정자 C, 계산 작업자 W, 기존 결과 보관 서비스 R. 기존 R의 아래 계약은 변경하지 않는다.

## Constraints
입력은 민감 정보가 없는 최대 8개 정수이며 각 값은 0 이상 1,000,000,000 이하이다.
단일 신뢰된 사내 호출자와 한 C·한 W를 사용한다. 인증·다중 사용자·작업 취소·자동 확장은 이번 개발 범위 밖이다.
W는 계산만 하며 R이나 원장에 쓸 권한이 없다. C만 내구성 원장과 R 발행 권한을 갖는다.
소프트웨어 재시작을 지원하되 원장 디스크 소실을 자동 복구한다고 약속하지 않는다.
