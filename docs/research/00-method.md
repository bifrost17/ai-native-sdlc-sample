# 세션 공통 최소 약속

방법(어디서 찾고 어떻게 평가할지)은 각 세션의 자율이다. 결과를 다른 세션과 나란히 놓기 위한 약속만 적는다.

- 판정 낱말은 셋: **채택** · **기각** · **보류**(이유 필수). 설계분은 「설계」로 따로 표시.
- `candidates.md` 표의 열: 이름 | 출처 URL | 판(sha/태그) | 라이선스 | 최근 갱신 | 사용 신호 | SKILL.md 형식 | 트리거 문장 | 덮는 조항 | 판정 | 이유. 조사 시각(UTC)을 표 위에 적는다.
- `coverage.md`: 행 = 정책 조항 ID(`policies/*.md` 의 B1, C1, U1, S1 …), 열 = 스킬. 칸 = 덮음/부분/—. 아래에 「겹침」「모순」「빈칸과 이유」 세 절.
- `raw/` 파일 이름 `NN-<무엇>.txt`, 머리 세 줄 `CMD:` `AT_UTC:` `RC:`. 가져온 SKILL.md 사본은 `raw/<name>@<sha>.SKILL.md`.
- 시각은 UTC ISO-8601. 수치(별·갱신일)는 조사 시각의 값.
- 열지 않은 것은 적지 않는다. 없으면 「없음」.
