## 4. 없음

- **다섯 절(problem · proposed outcome · affected users and systems · constraints · open questions)을 그 이름 그대로 쓰는 마켓 스킬**: 없음. `speckit.assess.define`(P·O·U·비목표·지표·미해결)과 `ideate`(같은 다섯을 다른 이름으로)가 가장 가까웠고, 둘 다 산출 문서가 더 크다.
- **「승인 = PR 머지, 별도 승인 파일 없음」을 규칙으로 적은 마켓 스킬**: 없음. 대부분 상태 필드(Draft/Review/Approved)나 별도 승인 단계를 둔다.
- **originator 의 말을 그대로 보존하라고 지시하는 마켓 스킬**: 없음(가장 가까운 것은 spec-kit `assess.intake` 의 "Quoted original").
