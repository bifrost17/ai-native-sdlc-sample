# OpenWebAgent 이력 조사 coverage 색인

수집 snapshot은 2026-10-03, `main`은 `a08295f2f7f492efd3ef4787c4ed3d1a1d8f118e`다. inventory의 접근 가능한 34개 개발 entity(번호 intent 30개, 번호 없는 사건 4개)를 현재 조사 보고서에 대조한 색인이다. **coverage 완료를 선언하지 않는다.** 0018 authority 후속과 0001 T2/T3 보완을 반영했지만 0018 pure state 전수 검토와 0001 94개 gate 전량 감사·실행은 완료하지 않았다. 이 표의 상태는 보고서의 분석 범위 상태이지 제품 개발 완료 상태가 아니다.

상태 정의: **검토 완료**는 명시된 보고서 범위를 분석했다는 뜻이며 원문 이력 전체 재검증이나 런타임 재실행을 뜻하지 않는다. **중요근거부족**은 사건 수준의 중요한 공백이 남았음을 보고서가 밝혔다는 뜻이다. **미검토**는 보고서가 특정 하위 범위를 미검토로 남겼다는 뜻이다. `미검토`는 당시 제품 작업이 미완료였다는 판정과 구분한다. 근거 링크는 해당 case 보고서의 정확한 경로로 연결한다.

PR 수는 수집 inventory의 사건별 연결 수다. 하나의 PR이 여러 개발건에 연결될 수 있으므로 합계는 고유 PR 수가 아니다. #421은 0023과 0025에 함께 연결되어 양쪽 수에 포함된다. 채택 뒤 미매핑 PR 5건(#268/#404/#363/#326/#301)은 번호 없는 사건 4개로 묶었다(#268/#404가 같은 정책 목적). pre-adoption 미연결 PR 122건은 채택 경계에 따른 모집단 제외이며 인과/계보가 없다는 주장은 아니다. 경로 root별 목록은 [curated-scope-adjudication.json](../../../.local/research/openwebagent-template-history/20261003/collection/api/curated-scope-adjudication.json)에 보존한다.

## 0018 후속 보고서와 상태 경계

- [0018 pilot](cases/0018-desktop-feature-port.md): **중요근거부족**. 개별 작업 전부의 구현·리뷰 흐름을 다루지 않았고 T26 회귀/성능/불변 빌드/릴리스, #435 등은 남아 있다. 모델 계획서의 Astra/Opus/Sonnet 표기는 실제 레인 실행 증거가 아니다.
- [middle follow-ups](cases/0018-followups-middle.md): 지정된 T06/07/09/10/11/12/13/15/16을 보완한다. 보고서는 선택한 코드·시험 diff 검토와 제한된 실행 증거라고 명시한다. 전체 0018 완료를 뜻하지 않는다.
- [late follow-ups](cases/0018-followups-late.md): T17 및 T19–T25의 선택 계약/첫 인도/후속 수정 이력을 보완한다. 런타임 증거는 제한적이고 전체 0018이나 #435 완료를 선언하지 않는다.
- [authority follow-up](cases/0018-followups-authority.md): T14 권한·준비 수명과 T26 인도의 주요 사건을 검토했다. 보고서는 실행 증거가 제한적이고 일부 하위 경계를 미검토라고 구분한다.

현재 34개 entity에 각각 분석 보고서는 연결되어 있지만, 이는 원문 역사 전수 검토를 뜻하지 않는다. 0018 보고서들은 선택된 사건 보완이며 pure GoalWatch 상태조합, GoalControl retained authority 도달 경로, DTO portability 전수는 미검토다. 0001의 T2/T3 주요 경계도 보완했지만 94개 gate 전량 실행이나 감사를 완료하지 않았다. 이 색인은 “원문 task 전체를 조사자가 읽지 않음”과 “당시 개발이 끝나지 않음”을 별도 필드로 관리한다. 예를 들어 0031은 문서 계약 분석은 검토 완료지만 보고서상 implementation 미착수/#470 open이고, 0033은 보고서상 #475 open 및 main 미병합이다. 반대로 #435나 다른 미완료 제품 작업은 조사 공백을 자동으로 뜻하지 않는다. 각 사건 행의 공백 열과 보고서 근거를 함께 읽는다. 34개 entity 모두 분석 보고서가 연결됐다는 coverage inventory의 사실과 case 안에 보고된 조사 미검토·제품 미완료 범위는 서로 다른 주장이다.

OS/모델 열은 각 보고서가 실제로 기록한 증거만 요약한다. 계획된 reviewer/model label, 브랜치명, WSL 경로, CodeRabbit status를 실제 개발 실행 환경 증거로 승격하지 않았다. 원문 전체를 보지 않았거나 재실행하지 않은 경우는 해당 행의 공백에 남겼다.
