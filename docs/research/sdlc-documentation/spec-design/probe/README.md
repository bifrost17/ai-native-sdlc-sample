## 최종 인계와 회귀

실제 AGENT 산출물의 바이트 사본: [intent](artifacts/intent.md), [spec](artifacts/spec.md),
[plan](artifacts/plan.md). root가 쓴 양식 예시와 구별한다. spec은 목적·기존 제약을 바꾸지 않고,
담당자 조회의 기본 상태와 포함 옵션·오류 계약을 바꾼 이유를 담는다. plan은 그 판을 참조하고
기존 명령·JSON·무변경 조회와 새 분기·실패 경로를 확인할 작업을 남겼다.

root가 시작·종료 시 기존 3개 시험을 실행해 통과했다. [종료 시 출력](baseline-regression.log).
tracker.py·기존 시험·데이터·입력 intent는 2dd4386과 바이트가 같고, 종료 worktree는 깨끗하다.
새 기능과 손상 JSON 경로는 계획만 세웠으므로 그 구현을 검증했다고 쓰지 않는다.

초기 예시의 잘못된 “기존 I/O 검증” 표현이 실제 초안에도 전파되어 root가 양쪽 예시를 R2에서
바로잡았다. 모델이 코드를 읽었다는 사실만으로 이해가 항상 정확해지지는 않았다. 빈 문자열 오류도
HUMAN 리뷰로 수정됐다. 이를 스크립트나 추가 필수 양식 항목으로 막으려 하지 않았다.

CLI 경과 합계 약 546초, CLI가 보고한 list 기준 비용 추정 합계 약 $1.69다. 준비·HUMAN 검토 시간이나
설계용 Fable 비용은 별도이며 실제 청구액을 뜻하지 않는다. 모든 호출은 rc=0이고 도구 거부는 없었다.
미실행 semantic eval을 대체해 같은 점수를 산출한 것은 아니며, 별개 부분 관측으로만 사용한다.
