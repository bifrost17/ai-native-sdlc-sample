17db139의 spec을 읽었다. 담당자 조회의 요구·설계는 내가 준 결정을 잘 반영했다. 인계 전에 세 군데를 보완하자.

첫째, 실제로 읽은 tests/test_tracker.py에는 list/show/complete 시험 세 개가 있고 I/O 오류 시험은 없다. AC3가 기존 시험이 오류 처리까지 증명하는 것처럼 읽힌다. 기존 검증으로 확인할 부분과 계획에서 추가 확인할 부분을 구별해라. 아직 새 기능을 실행한 것은 아니라는 점은 지금처럼 유지하자.

둘째, 이번 격리된 실험 프로젝트의 제품 오너/엔지니어로서 검증 명령은 python3 -m unittest discover -s tests -v, 증거 위치는 보존하는 CLI 대화와 커밋으로 확정한다. PROBE-CONTEXT의 역할 위임 안에서 내리는 실험 결정이며 실제 회사 정책을 대신하지 않는다. 이 범위에서 그 우려는 해소된 것이다.

셋째, disable-model-invocation은 선택 방식 옵션이지 판 정보가 아니다. 실제로 사용한 지침의 출처와 확인 가능한 Git 판을 참조 기록에 써 줘.
