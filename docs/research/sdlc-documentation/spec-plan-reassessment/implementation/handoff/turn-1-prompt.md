# W01 새 세션 인계 — 첫 요청

당신은 이 기능을 처음 인수하는 개발 에이전트다. 여기서는 문서만 읽는 인계 연습을 한다. 제품 코드를 만들거나 실행·설치·커밋하지 않는다. 합성 context의 기존 시스템·경로·명령은 이 연습에서 주어진 전제이고, 문서 검토/작업 재구성은 이미 허가됐다. 실제 제품 승인이나 실행 성공을 주장하지 않는다. 원 작성 대화와 이전 리뷰는 읽지 않는다.

먼저 docs/research/sdlc-documentation/spec-plan-design/candidate/ 아래 skills/design-spec/SKILL.md, skills/plan/SKILL.md, skills/spec-policy-pass/SKILL.md, skills/tdd/SKILL.md와 examples/W01/context.md, intent.md, spec.md, plan.md를 읽는다. 관련 정책 링크는 필요하면 읽는다. 해당 경로를 직접 읽는 것이며 설치나 자동 스킬 호출로 표현하지 않는다.

이제 개발을 인수한다면 어떤 첫 작업/시험부터 진행하고, 다음 PR·통합·공개로 어떻게 이어갈지 구체적으로 설명해줘. 작업을 시작할 때 확인할 실제 경로·명령·관찰할 실패와 완료 증거가 드러나야 해. 현재 문서만으로 결정된 내용과 뒤에 물어야 할 입력을 구별하고, 서로 맞지 않거나 구현 결과를 달라지게 할 중요한 공백만 알려줘. 아직 구현 코드를 작성하지 말고, 내가 답을 읽은 뒤 후속 요청을 주겠다.
