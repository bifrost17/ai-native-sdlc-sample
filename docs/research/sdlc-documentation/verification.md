## 출처와 보관 파일

[전체 manifest](sources.json)는 레퍼런스 12개와 실제 사례 2개의 하위 manifest를 합친 것이다.
추가 후보와 공개 문서의 링크도 별도 종류로 포함한다. 수량을 원본 양식 수와 혼동하지 않는다.

| 구분 | 수량 | 확인 내용 |
|---|---:|---|
| 전체 출처 항목 | 184 | 파일 출처와 링크 전용 항목을 합한 수 |
| 로컬 보관 파일 | 162 | 경로 존재, 중복 경로 없음, 바이트 수·SHA-256 일치 |
| 링크 전용 항목 | 22 | 로컬 파일·바이트·해시를 만들지 않음 |
| 원본 빈 양식 | 28 | 고정된 상류 URL에서 다시 내려받아 보관본 SHA-256과 전부 일치 |
| 실제 사례의 채워진 산출물 | 9 | 빈 양식 수와 구분, 구현/보관 commit을 파일별로 기록 |
| 선별한 API 사실 JSON | 14 | GitHub 응답 원문 사본이 아니라 선택 필드의 재직렬화로 표시 |
| 하위 출처 manifest | 14 | 전체 색인의 항목·개수·manifest 자체 해시와 일치 |

162개에는 양식, workflow, 프롬프트, 예시, 그림, 발췌, 라이선스, patch, API metadata가 포함된다.
따라서 모두를 ‘상류 원문 파일 162개’라고 부르지 않는다. MD 경로에 오류 HTML을 잘못 저장한
파일이 없는지 확인했고, 레퍼런스·사례 폴더에 색인에 빠진 자료가 없는지도 대조했다.

Fuchsia 원문은 Gitiles base64 전송을 해제한 바이트를 기준으로 대조했다. TensorFlow RFC의
상대 경로 그림 두 개도 원본으로 보관했다. Anthropic 예시 추출에서 우리 평가 주석을 제외하고,
추출 입력 해시와 로컬 저장소 판을 남겼다. 이를 Anthropic 원문 커밋으로 표시하지 않았다.

## 문서와 링크

우리 분석·색인·보고서·비교표·계획·검증 문서와 상위 연구 색인의 로컬 링크를 확인했다.
원문에 남아 있는 상류 저장소 상대 링크나 placeholder는 검사 범위에서 구분하며 원본을
고치지 않았다. 해당 자료의 원래 맥락은 manifest의 원문 URL에서 확인할 수 있다.

별도 검토 에이전트가 북극성·Google·Fuchsia·TensorFlow·Kiro·MADR 분석과 종합 보고서·비교표를
원문과 대조했다. 중요한 사실 오류나 북극성과 자체 권고의 혼동을 발견하지 못했다.
이 검토는 오류가 전혀 없다는 보증이 아니라 조사 결과에 대한 추가 근거 검토다.

## 기존 저장소 검사

`make check`가 종료 코드 0으로 완료되었다. [실행 로그](validation/make-check.log)를 보관했다.
양식 설계 접근 권고를 추가한 뒤에도 `make check`를 다시 실행해 통과했고, 로그는 그 실행으로 갱신했다.
이때 분석 문서 23개의 로컬 링크 281개와 출처 파일의 무결성을 다시 확인했다.

```text

test_hooks: 28 passed, 0 failed
8 passed, 0 failed
PASS  managed-settings 키·훅 계약
```

- Python unittest: 96 tests, 성공, 기존 조건에 따른 skip 1개.
- Hook 검사: 28 passed, 0 failed.
- Eval harness 검사: 8 passed, 0 failed.
- Managed settings 키·hook 계약 검사: PASS.

이번 변경은 연구 문서·자료와 상위 연구 색인에 한정된다. 기존 운영 템플릿·정책·스킬은
수정하지 않았다. 검사용 임시 다운로드·집계·대조 스크립트는 연구 결과나 배포 템플릿에 넣지 않았다.

## 검증하지 않은 범위

프레임워크 CLI나 skill을 설치·실행하지 않았고 외부 제품 코드를 실행하지 않았다. OpenSpec 사례의
성공 CI는 해당 상류 SHA의 공개 실행 기록이며 우리의 재현 실행 결과가 아니다. Opentu 사례의
CI 성공, 두 사례의 최초 대화·계획 작성 순서, SDD의 정량적 품질·비용 효과는 확인하지 못했다.
운영 양식 반영 및 Claude Code와의 개발 대화 실험은 이번 조사 완료 조건에 포함되지 않는다.
