# 독립 자문과 root 판단

2026-09-11 · 시작한 저장소 판 `abd6b28` / `codex/release-controls`.
이 작업은 리서치와 설계 자문이다. 템플릿 적용·설치·행동 실험의 통과 판정이 아니다.

Fable의 실제 관측 모델은 `claude-fable-5-1`이다. Read만 허용했고 다른 리뷰어 답변이나 root의
초안은 전달하지 않았다. 공개 SKILL.md는 읽을 참고 데이터로 제공했다. 원문 요청에 있던 후보
요약은 공유했으므로 정보 출발점까지 완전히 독립된 연구라는 뜻은 아니다. Fable은 Glebis·Addy
원문을 읽지 않았다고 답했고, 그 부분의 판단은 제공 요약에 기반한다.

CLI는 rc=0, success/is_error=false, 권한 거절 0으로 완료했다. 약 12분과 약 $6.09는 이번
Fable 설계 자문의 CLI 보고값이다. 외부 TDD 스킬을 실제 실행한 비용이나 성능 비교값이 아니다.
비공개 추론·세션 내부 메시지는 내보내지 않았고 최종 자문 답변만 보존했다.

## 수용한 공통 의견

- TDD의 반복 절차는 별도 작은 자체 스킬에서 관리한다. 특정 외부 스킬 전체를 의무화하지 않는다.
- 팀 규칙은 항상 읽는 지침에 짧게 남긴다. spec은 계약·설계·관찰 가능한 AC, plan은 이번 행동의
  실제 테스트·경로·선행 순서·통합 검증을 소유한다.
- 현재 기능 예시가 구현 후 테스트를 가르치는 점은 보강 때 함께 수정한다.
- 실제 RED/GREEN 근거는 기존 실행/PR 기록에 둔다. plan에 모든 cycle·로그·별도 원장을 만들지 않는다.
- 결함의 선행 재현 커밋과 일반 기능 TDD를 구분하고, 한 PR에 테스트·구현·문서를 함께 담는다.

## Fable 의견 중 그대로 채택하지 않은 부분

1. **TDD를 기본값으로 낮추고 리뷰는 결과만 본다는 결론.** 사용자는 동작 개발의 TDD를 의무화하고
   싶다고 했다. 완전한 사후 증명이 어렵다는 사실은 의무를 권장으로 바꿀 이유가 아니다.
   과정의 관측·이탈/복구와 결과의 적합성을 구분한다. 사후 회귀 시험을 선작성의 증거로 오인하지 않는다.
2. **스킬이 스무 줄을 넘으면 분리의 반론이 이긴다는 기준.** 근거 없는 줄 수 상한이다. 필요한
   판단과 예외를 빠뜨리지 않으면서 공통 절차를 짧게 두고 사례는 필요할 때 읽도록 하는 편이 적절하다.
3. **기존 시험 변경 허용 사유를 지나치게 닫는 규칙.** 기존 spec이 그대로여도 시험 자체의 오류,
   잘못된 fixture·관찰 지점·기대값은 수정할 수 있다. 새 계약이면 spec도 고치고, 기존 계약에 맞추는
   시험 정정이면 그 근거를 기록한다. 고정 재현 시험 보호 단계는 별도로 유지한다.
4. **모든 기대값을 먼저 AC/plan에 넣는 해석.** spec은 중요한 행동·대표 사례·불변식을 충분히
   담아야 하지만, 이미 정한 계약의 추가 사례까지 모두 문서에 복사할 필요는 없다. 테스트의 독립
   기대값은 수락된 계약·정책·검증된 계산 예시 등에서 도출할 수 있다.
5. **새 세션은 실패 시험이 남은 RED임을 알 수 있다는 가정.** 환경 오류나 기존 회귀일 수 있다.
   계획·변경 내역·기존 실패 이유를 확인해야 한다. 원장이 없다는 이유로 인계 문맥도 버리지 않는다.
6. **PR head의 GREEN이면 main도 항상 GREEN이라는 단순화.** 최신 main과 합친 결과에서 관련
   검증을 해야 한다. 기존 Git 정책을 유지한다. 모든 중간 커밋에서 전체 suite를 재실행하는 규칙도
   새로 추가하지 않고, 의미 있는 작업·PR·완료 경계와 변경 영향에 맞춘다.

또한 Fable의 표에서 스킬·리뷰에 테스트 약화 지침을 중복하지 말라는 의견은 실행 예방과 사후
판정을 구분해서 해석했다. 같은 상세 설명을 복사할 필요는 없지만 스킬에는 하지 말아야 할 행동,
리뷰에는 확인할 기준이 필요하다. 역할 간 최소 연결을 중복이라는 이유로 지우지 않는다.

이 판단은 리뷰어 만장일치나 PASS 표를 만들기 위한 것이 아니다. root가 사용자의 선택과
프로젝트 경계를 기준으로 채택·수정·기각한 자문 기록이다.

주석도 변경하지 않았다. 후속 구현 시 사용판 전달과 행동 실험까지 별도로 수행해야 한다.
