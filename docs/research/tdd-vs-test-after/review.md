독립 검토에서 P1 0건, P2 3건을 발견했다. 수정 후 검토한 범위에서 미해결 P1/P2는 없다. 이는 모든 자료를 전수 검증했다는 인증이 아니다. 일부 논문·핵심 실험 원자료·정책·실행 보고를 표적 대조했으며, 72건의 모든 diff·CI를 별도 검토자가 다시 조사하지는 않았다.

## 종합 과정에서 바로잡은 사항

- 웹 PR의 최신성은 저장한 검색 후보 안으로 제한했다. React Search API의 422 응답, 후보 100건 상한, 큰 CI 목록의 일부 페이지만 조회한 한계를 남겼다.
- Next.js #98504는 주된 목적이 성능 최적화여서 리팩터링 표본에서 제외하고 다음 적격 사례로 교체했다. 최종 웹 표본은 같은 커밋 37건, 관련 테스트 미변경 7건, 구현 커밋 뒤 테스트 1건이다.
- Superpowers의 정책은 main에서 읽었으며 최근 일부 PR은 다른 브랜치에 병합됐음을 밝혔다. 커밋의 author/committer 시각과 실제 공개 시각을 같다고 추정하지 않았다.
- TENET은 테스트 정보 제공 시점, 구현 노출 연구는 테스트의 독립성에 관한 근거로 제한했다. 둘을 엄격한 TDD 작성 순서의 효과로 합치지 않았다.
- TDDev의 평가 지표·표본·표 사이 불일치, TDAD의 서로 다른 분모, Santos 원문의 본문·도표 수치 차이를 상세 카드에 기록했다.

## 파일 검증과 보관 한계

원문 PDF 17개를 파싱하고 텍스트 추출 가능 여부를 확인했다. 원문 폴더의 파일별 SHA-256·용량을 기존 출처 메타데이터와 대조하고 통합 manifest를 만들었다. JSON/JSONL 구문, 작성한 보고서의 로컬 링크, 8개 프로젝트별 9건·유형별 3건·병합 날짜 범위를 확인했다. 최신 수치와 결과는 [파일 검증 기록](data/artifact-check.json)에 있다.

원문 논문·프로젝트 코드·첨부 실험 코드는 실행하지 않았다. Finster 데이터 재집계는 공개 숫자의 확인이며 에이전트 실험 재현이 아니다. PDF 파싱은 모든 페이지의 시각적 조판 검수가 아니다. HTML 저장은 사이트 전체의 오프라인 미러가 아니다. 비공개 로그·익명 저장소·다운로드하지 않은 대용량 보충 ZIP의 한계는 [원문 목록](originals/README.md)에 남겼다.

보고서의 권고는 이 범위의 공개 근거에 기반한다. 전체 개발 시간·장기 유지보수·실제 웹앱의 동일 비용 비교가 부족한 부분은 불확실성으로 유지했다.
