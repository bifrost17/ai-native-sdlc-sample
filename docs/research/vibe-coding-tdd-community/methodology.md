# 커뮤니티 조사 방법

조사일: 2026-09-12. 최종 질문은 사용자의 추가 지시에 따라 **‘바이브 코딩·AI 보조 개발에서
TDD 스킬을 실제로 사용하는가, 계속 유지하는가, 선택하거나 중단하는가’**로 좁혔다.
처음 조사한 일반 TDD·test-after 경험은 배경 자료로 보존하고 스킬 채택 사례와 구분한다.
기존 유명 프로젝트 정책/PR 조사와도 구분한다.
이 조사는 커뮤니티 경험의 질적 조사이며 전체 개발자의 채택률이나 방식의 인과적 효과를 추정하지 않는다.

## 탐색과 종료 기준

2025-02-01부터 조사일까지 공개된 글을 대상으로 한다. 게시일과 현재 댓글 작성일·수정 가능성을 구분한다.
Reddit의 ClaudeAI·ClaudeCode·Cursor·vibecoding, Hacker News, 국내 GeekNews·개인 개발자 글·
공개 개발 커뮤니티를 탐색한다. 오래된 경험만 모으지 않도록 2026년 글도 찾되 최신성만으로 질을 판단하지 않는다.

1. `TDD`, `test first`, `AI coding`, `vibe coding`과 실제 사용·어려움·불사용 표현을 조합한다.
2. `vibe coding tests`, `writing tests`, `testing workflow` 등 TDD를 전제하지 않는 검색도 병행한다.
3. 검색 결과는 후보 발견용이다. 게시글 본문·관련 부모/답글을 읽고, 검색 요약과 다른 내용은 원문을 따른다.
4. 질문글의 응답자, 실제 워크플로 서술, 시행착오를 우선한다. 권장·출시 홍보·별점·다운로드는 채택 증거로 세지 않는다.
5. Reddit 6~8개, HN 4~6개, 국내 3~5개 유용한 글/스레드를 목표로 한다. 같은 링크의 재게시·번역은
   독립 사례로 중복 계산하지 않는다. 실제 경험이 부족하면 그 사실을 기록하고 홍보 글로 수를 채우지 않는다.
6. TDD 지속 사용, 부분 사용, 구현 후 검증, 선작성 지시를 지키지 못한 사례를 찾고 추가 탐색이 같은
   쟁점을 반복하면 종료한다. 대표 설문을 찾지 못하면 사용률 추정의 빈칸을 그대로 둔다.

영어권 HN과 국내 자료는 각각 별도 조사자가 탐색하고, 주 조사자는 Reddit과 브라우저 열람·최종 종합을 맡는다.
탐색·작성은 `gpt-5.6-sol/high`, 근거와 일반화의 최종 독립 검토는 별도로 수행한다.

## 무엇을 구분하는가

| 구분 | 기록할 내용 |
|---|---|
| 용어 | 코드까지 사람이 검토하는 AI 보조 개발인지, 구현을 거의 읽지 않는다고 명시했는지, 정보가 없는지. ‘vibe’라는 이름만으로 추정하지 않음 |
| 방식 | 의미 있는 실패 시험 선작성/확인→구현→정리의 구체 서술, TDD라고만 부른 지시, 선행 일괄 시험, 구현 후 시험, 기존 시험, 직접 관찰, 무자동시험 |
| 주장 수준 | 본인 사용 보고 / 권장·의견 / 타인에 관한 전언 / 공개 코드·프롬프트·로그로 연결되는 사례 |
| 작업 조건 | 앱·언어·UI/서버·기존 코드 여부, 도구·모델·시점. 없으면 미상 |
| 효과 | 작성자가 보고한 장점·실패·시간/토큰/검토 부담. 통제 비교나 측정 자료가 없으면 정량 효과로 채택하지 않음 |
| 인계 | 사용자 handle·게시일·직접 댓글/글 URL·부모 맥락·로컬 원문 위치·열람/보관 한계 |

같은 사람이 같은 스레드에서 반복 발언한 것을 서로 다른 사용자로 세지 않는다. 테스트를 실행했다는 말이나
Superpowers 설치만으로 엄격 TDD를 실행했다고 인정하지 않는다. TDD를 썼다가 시험 설계를 개선한 사례를
‘TDD 포기’로 바꾸지 않는다. 테스트가 많다는 사실은 시험 품질·회귀 보호·제품 품질을 증명하지 않는다.

### 추가 지시 후의 스킬 판정

- 이름 있는 TDD 스킬·개인 TDD 스킬 사용을 명시한 경우를 우선한다. Superpowers 전체 사용만 밝히면
  TDD 스킬 사용은 미상이다. TDD가 포함된 프레임워크 사용 이유를 명시한 사례는 그 수준으로 기록한다.
- 상태는 지속 사용 / 선택적 사용 / 다른 TDD 스킬로 대체 / 중단 시험 / 중단 / 사용 예정 / 미상으로 나눈다.
  바꿔 볼 생각이라는 댓글을 실제 전환 완료로, 프레임워크 중단을 모든 TDD 스킬 중단으로 바꾸지 않는다.
- SKILL.md, slash-command prompt, AGENTS.md 규칙, 훅, 다중 에이전트 하네스는 별도 형식이다.
  기능이 비슷해도 같은 배포·호출 방식이라고 가정하지 않는다.
- 공개 스킬 원문은 지시의 내용과 식별을 확인하는 자료이며, 사용자 설치·호출·실행의 증거는 아니다.
  조사일의 고정 버전을 과거 댓글 작성자가 쓴 버전으로 소급하지 않는다.
- 추가 영문 3~5개, 국내 2~4개 유용한 사례를 목표로 삼고, 기존 글의 재분류와 중복 발견은 새 독립
  사용자 수로 합산하지 않는다. 대표 설문이 없으면 사례 목록으로 답하고 사용률은 산출하지 않는다.

## 브라우저와 보관

웹 검색/원문 도구로 글을 찾고 Aside Browser에서 선택한 공개 스레드의 본문·댓글 맥락을 확인한다.
접근이 막히면 우회하지 않고 원문 도구로 읽힌 범위와 미열람 부분을 구분한다. 댓글을 달거나 투표·가입·
메시지를 보내지 않는다. 사용자 계정 영역·로그인 토큰은 보관하지 않는다.

허용되는 공개 HTML/API 원문은 가능한 범위에서 전체 보관한다. 브라우저는 실제 열람된 본문·댓글을
읽기 사본으로 저장하고 전체 서버 응답·숨겨진 댓글 전체와 구분한다. 원문 URL·조회일·파일·SHA-256을
출처 목록에 남긴다. 서술과 숫자는 원문과 대조하고, 로컬 링크·파일 해시·누락과 정책/경험 혼동을 별도 검토한다.
