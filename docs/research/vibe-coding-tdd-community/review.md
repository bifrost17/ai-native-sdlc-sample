# 독립 검토와 최종 반영

검토일: 2026-09-12. 탐색은 분야별 `gpt-5.6-sol/high`, 독립 검토는 `gpt-6-astra/high`로 분담했다.
[검토자의 원본 기록](working/review-notes.md)은 중간 지적과 확인 시점을 그대로 남긴다.
아래는 주 작성자가 최종 반영한 내역이다.

| 지적·점검 | 최종 반영 |
|---|---|
| 햄스터아저씨의 비교 후 권고를 실제 지속적인 켜기/끄기 관행으로 확대 | 제목·상태·본문·종합을 **비교 수행 + 조건부 사용 권고**로 교정. 실제 지속 관행은 미공개 |
| Matt Pocock TDD 사용자의 행동을 다른 작성자의 Superpowers 삭제와 혼합 | 해당 사용자는 **brainstorming을 유지하면서 TDD를 대체**했다고 수정 |
| ‘실제 RED 실행’ 제목이 외부 실행 검증으로 읽힐 가능성 | **RED 순서 준수 자기보고**로 명시 |
| 비브로스의 선택적 호출 정책 누락 | 명시 TDD 요청에서만 호출하도록 구성한 원문 정책을 보충. 정책 준수율로 일반화하지 않음 |
| `tonyboi76`의 자체 스킬을 설명하는 부모 댓글 보관 부족 | [R08](sources/reddit/R08-superpowers-worth.json)에 부모 `onz74u1`과 후속 `onzk3lr`를 함께 보관하고 노트에 연결 |
| HN 변경 뒤 테스트 실행을 구현 뒤 테스트 작성으로 오독할 가능성 | `raw_anon_1111`은 **변경 후 검증 / 작성 시점 미상**으로 교정 |
| 세나의 자동화 테스트 미공개를 TDD 미사용으로 단정하는 제목 | **구현 후 수동 확인 경험(자동화 테스트 미공개)**으로 교정 |

검토자는 주요 사례 7건, HN 보조 1건, 영문 추가 스레드 2개의 주요 댓글을 원문과 대조했다.
Peerless-Paragon의 TDD 유지·전략 수정, 프레임워크 중단과 TDD 전면 포기의 차이, 작성자의
사용 예정과 사용 완료, 현재 스킬 정의와 과거 버전의 차이도 확인했다.

표본의 대표성이나 TDD 효과를 검증한 것은 아니다. 실제 작성자의 비공개 로그와 코드 실행은 재현하지 않았다.
원문 공개 발언과 보고서 해석의 일치 여부를 검토했으며, 원문이 사실이라는 독립 보증은 아니다.

최종 파일·JSON·로컬 링크·원문 해시와 Reddit 계정 UI 정보 배제 확인은 [artifact-check.json](artifact-check.json)에 있다.
문서 조사에 맞춘 산출물 검증이며 SDLC 구현 테스트를 다시 실행하지 않았다. 국내 작업 노트의 공개 예제 4/4 재실행은
별도 배경 증거로만 보존했고, 역사적인 테스트 선행 순서나 스킬 호출을 입증하는 자료로 쓰지 않았다.
