# 작성 양식과 예시

현행 양식·작성 예시는 유일한 [TDD 선택형](../../tdd-optional/project/docs/sdlc-authoring/README.md)에서
함께 관리한다. 작업별 방식·선택 이유·독립 기대와 검증 순서를 계획한다.

양식은 `tdd-optional/project/templates/`, 작성 스킬 예시는 그 제품의 `examples/skills/`에 있다.
[Claude Code 설치](../../tdd-optional/org-skills/claude/README.md)와
[Codex 설치](../../tdd-optional/org-skills/codex/README.md)는 같은 원본을 사용한다.
이 디렉터리는 제작 안내용 연결점이며 별도의 양식·예시 정본을 보관하지 않는다.

기존 제작 예시와 실행 기록의 경로는 당시 Git 커밋을 기준으로 읽는다.
[분리 전 원문](https://github.com/bifrost17/ai-native-sdlc-sample/tree/13376e8049c5650c0fe3a8a258a6595f8d3ada8f/docs/sdlc-authoring)과
[과거 분리 구조](../decisions/template-variants.md)에 출처가 남아 있다. 현재 구조는 [단일 템플릿 결정](../decisions/single-template.md)을 따른다.
