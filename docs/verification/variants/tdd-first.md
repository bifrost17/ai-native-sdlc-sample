# TDD 기본형의 보존 범위

2026-09-12. [tdd-first](../../../tdd-first/README.md)는 기존 test-first 기본과 예외를 유지한다.

제품은 `codex/use-template-0026@84a77b3890cfdc97f3c6603f433e1382453ca261`에서 가져왔다.
`project/`의 71개 파일이 원본과 byte 단위로 같고 파일 집합도 같다. PROJECT-POLICY, plan과 작성 예시,
리뷰·사람 의사결정 구조를 이번 분리에서 바꾸지 않았다. [파일별 해시](baseline.json)

팀 패키지는 `13376e8`의 `org-skills/`에서 옮겼다. 기존 `intent-sdlc-skills` 식별자를 유지하고 배포 위치·
독립 설치 안내·동봉 자료 링크를 고친 버전을 0.1.8로 기록했다. 핵심 TDD·sdlc-feedback·두 검증자 본문은
이전과 byte 단위로 같다. OpenCode 설치는 새 경로의 동봉 원본과 patch를 사용하며 기존 고정 커밋의
실험 기록은 역사적 근거로 연결한다. 제품 본문 보존을 패키지 전체가 무변경이라는 뜻으로 확대하지 않는다.

루트의 중복 양식·예시는 제품 안으로 모았다. 제작용 작성 스킬은 이 판의 정본으로 연결하고, 원래의
훅·연구·실험 도구를 제품에 자동 설치하지 않는다. intent 양식은 선택형과 같으며 기존 제작 스크립트의
기본 경로만 이 판으로 옮겼다.

별도 제품 사본에서 일반적인 작은 구현 요청을 받은 에이전트가 정책을 읽고 TDD를 진행했다.
최종 7개 시험과 독립 계산 검증이 통과했다. [작업자 실행 기록](evidence/first/evidence.md),
[독립 최종 결과](evidence/verification.json). 스킬의 native 발견·자동 호출이나 웹앱 전체 흐름을
새로 검증한 결과는 아니다. 전체 확인 범위와 한계는 [검증 기록](README.md)에 있다.
