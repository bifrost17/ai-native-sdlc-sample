# 프로젝트 정책: 임직원 작업 상태 조회 (평가용)
Owner: 정책 오너.

## P1 이름·표기
제품: 작업 상태 조회. 상태 이름: 대기, 처리 중, 완료, 실패. 날짜·시각 형식은 팀 기본값을 따른다.
화면 사용자의 시간대는 KST다. 버튼 이름: 다시 조회.

## P2 민감 데이터·보존 기간
employee_email과 employee_phone은 임직원 개인정보이며 상태 조회에 필요하지 않다.
작업 ID와 내부 임직원 ID로 업무를 연결한다. 접근·변경 이력은 90일 보존한다.
근거: 이 평가 프로젝트의 운영 추적 기간으로 정책 오너가 정한 값이며 법정 기간을 주장하지 않는다.

## P3 사내 전제를 벗어나는 것
사내 임직원 전용 포털이다. 사외 사용자, 외부 데이터 전송, 별도 규제 대상은 해당 없음.
이 프로젝트가 따로 정한 접근성 판·검사 방법은 없다.
