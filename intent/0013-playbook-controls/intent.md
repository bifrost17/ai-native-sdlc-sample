# Intent: 플레이북의 보호·정책 적용·등급별 대응을 실제 실행에 연결한다
Author: 프로젝트 오너 (요청자). Status: draft.
## Problem
보호 파일을 가리키는 경로에 `/./`가 들어가면 훅이 차단하지 않는다. 조직 스킬은 플러그인으로 분리됐지만 spec 지침과 평가 실행은 그 배포 경로를 충분히 반영하지 않는다. bands 워크플로는 2σ에서 없는 초안에 진단을 덧붙이라고 요청하며, 3σ 초안 생성 오류를 성공으로 숨긴다.
## Proposed outcome
플레이북 V6-14·V8-10의 파일 보호, V3-01·V3-14·V9-07의 조직 정책 적용과 설정 변경 평가, V13-07·V13-09의 등급별 대응이 실행 근거로 확인된다.
## Affected users and systems
템플릿을 사용하는 엔지니어와 정책 오너, 조직 스킬 플러그인, 훅, 에이전트 평가 및 bands CI.
## Constraints
- C1 사용자가 요청한 개선 1·2·4번만 보완한다. 3번의 의미적 채점과 정규식 판정은 변경하지 않는다.
- C2 북극성은 `docs/verification/north-star-playbook.html`이며, 원문을 보존하고 해당 평가 주석을 실행 증거에 맞춰 갱신한다.
- C3 스킬은 권고, 파일 보호·실행 분기는 결정론, 승인과 분류는 사람의 몫이다. 절차·문서 승인 상태 검사기를 추가하지 않는다.
- C4 기존 테스트 파일을 고치지 않고 새 회귀 시험을 추가한다. Python 표준 라이브러리와 Bash 3.2를 사용한다.
- C5 2σ는 저장소 읽기 전용 진단, 3σ는 사람에게 넘길 제안 초안까지다. 자동 PR·머지·프로덕션 조작은 추가하지 않는다.
## Open questions
- 실제 모델·호스티드 CI에서 확인하지 못한 동작은 별도로 표시하고, 해당 실행 증거가 있어야 주석의 충실 판정을 높인다. 실행 환경 담당: 프로젝트 오너.
