# Intent: 가벼운 사용 템플릿의 중요한 결정과 인계를 실제 개발로 확인
Author: 프로젝트 오너 요청, Codex 기록. Status: draft.
## Problem
제작 저장소의 주석 근거만으로는 제작 자산을 덜어낸 사용 템플릿이 실제 대화형 개발에서 작동하는지 알 수 없다.
## Proposed outcome
사용자 결정의 유지와 계획·실제 변경의 연결을 작은 개발건으로 확인하고, 중요한 회귀가 없으면 관측 범위만 주석에 반영한다.
## Affected users and systems
템플릿을 채택할 팀, Codex HUMAN과 Claude Code AGENT의 로컬 실험.
## Constraints
사용자가 구현·실험·반복·통과 판단을 위임했다. 완벽한 가이드 재현을 목표로 하지 않는다. 템플릿 비대화·새 집행 스크립트·필수 특정 스킬을 추가하지 않는다. Claude는 Sonnet·low, 설계 검토는 사용자 허용에 따라 최고 수준.
## Open questions
운영·실제 조직 승인·새로운 규모의 일반화는 후속 실험 범위(프로젝트 오너). 현재는 F01 한 건으로 시작한다.
