# Spec: 유연한 PR 단위와 고정된 GitHub Flow
Upstream: intent.md@b90656e. Status: draft.
오너가 조사·템플릿 반영·최종 실험을 지시하여 draft에서 다음 단계를 진행한다. Codex root가 위임 범위에서 설계와 실험 통과를 판단한다.
## Requirements
- R1 일차 연구·공식 운영·실제 사례를 조사하고 AI 작성과 AI 리뷰의 효과, 관측과 인과, 벤더 측정과 독립 연구를 구분한다. 보편적인 LOC 임계값을 발명하지 않는다.
- R2 PR 크기는 응집된 목적, 변경 간 의존성, 검증·회귀·복구 가능성과 검토 부담으로 정한다. 독립 변경은 분리하고 기계적 변경·불필요한 과도 분할 등 큰 PR이 합리적인 조건도 설명한다.
- R3 사용 템플릿에 GitHub Flow를 묶는다. main과 짧은 작업 브랜치, Draft PR, 사람의 수락·검토, 선행 변경·병렬 worktree, 최신 통합 상태의 검증, merge commit 기본값, 통합 후 정리와 운영 인계를 연결한다.
- R4 중간 intent/spec/plan 수락은 대상 커밋과 책임자·결정 근거로 기록하며 문서별 PR을 강제하지 않는다. 최종 제품 변경은 PR로 통합한다. 전체 계획의 일부 PR을 전체 요구의 완료로 보고하지 않는다.
- R5 큰 요구는 필요한 조사와 계획에서 작업·의존성·예정 PR 범위를 정하되 작업/세션/서브에이전트/PR을 1:1로 강제하지 않는다. 단계·정책·리뷰·README 간 모순을 제거한다.
- R6 수정된 사용 기준선을 고정해 Codex HUMAN과 Claude Code Sonnet·low가 같은 세션으로 대화형 개발을 수행한다. 둘 이상의 구현 통합 단위와 최신 기반 회귀, 실제 판단·수정·인도를 관측하고 한계를 보존한다.
## Design
사용 후보 codex/use-template-0016에서 PR 크기와 GitHub Flow 문서 두 개를 추가하고 기존 진입점에 짧게 연결한다. 자세한 조사와 설계·실험 근거는 제작 main에 둔다. 단계별 브랜치를 강제했던 실험 프로토콜은 실험 목적에 맞는 PR 단위로 바꾸되 이전 기록을 보존한다. 외부 서비스 없이 작은 합성 CLI 사례를 사용하고 실제 GitHub PR 실험은 제품 main과 분리된 전용 통합 브랜치만 대상으로 한다.
## Constraints
새 정책 집행 코드·필수 스킬·숫자 기반 PR 차단 없음. 공개 실험에는 합성 입력과 공개된 대화·정제 근거만 담는다. 실험 통합을 제작 main에 머지하지 않는다. 실제 사람 간 권한 분리·운영 배포를 모의 역할과 혼동하지 않는다.
## Open questions from intent
최적 PR 줄 수는 검증된 보편 수치가 없으면 미확정으로 남긴다. 실험은 정책 사용 가능성을 확인하며 최적 크기의 통계적 비교가 아니다.
## Flagged concerns
서로 다른 파일도 의미상 의존할 수 있다. 단일 Git 커밋도 배포 중 스키마·실행 프로세스의 원자성을 보장하지 않는다. AI 리뷰 무지적은 결함 없음의 증명이 아니다. squash/rebase는 Upstream 커밋의 도달 가능성을 바꿀 수 있다.
## Out of scope
새 PR 오케스트레이터, 자동 승인·정량 크기 검사, 필수 stack 도구, 장기 develop/release 체계, 실제 프로덕션 배포, 모든 모델과 프로젝트에 대한 최적 크기 벤치마크.
## Acceptance criteria
- AC1 → R1/R2 조사 보고서가 사례·반례·한계·출처와 채택 근거를 담고, 사용 가이드는 간결하며 특정 LOC를 통과 기준으로 쓰지 않는다.
- AC2 → R3/R4/R5 사용 문서 전체가 같은 브랜치/수락 규칙을 안내하고 승인 원본·부분 완료·병렬 의존성·회귀를 추적할 수 있다.
- AC3 → R6 실제 사용 기준·데이터·동적 대화·Git/PR 결과·검증과 인도를 보존하고 중요한 실패를 수정·재확인한다. 전체 흐름 회귀와 미관측 범위를 구분한다.
- AC4 → R1~R6 제작 make check와 독립 verifier가 중요한 회귀를 발견하지 않으며 북극성 주석에는 실행으로 확인한 범위만 추가한다.
