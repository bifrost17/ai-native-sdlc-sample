# Spec: 팀 실행 진입점의 독립 문서 검토
Upstream: intent.md@6a4f18e4ed0b9eb6bd25935c4a5c79e5f8a508eb. Status: draft.
사용자의 목표 달성 위임으로 root가 설계·구현·실험을 진행한다.

## Requirements
- R1. 별도 팀 CLI는 프로젝트·작업 사슬·기준 커밋·사용자 프롬프트로 개발 Claude를 호출하고,
  그 응답을 최종 반환하기 전에 독립 Claude 검토를 실행한다. 후속 대화는 개발 세션을 resume한다.
- R2. 검토에는 최신 공개 업무 대화·수락, 실제 문서, 기준부터의 변경(커밋·미커밋·미추적 포함),
  개발 도구의 실행 근거를 전달한다. 작성자의 요약이나 파일 수정 여부만으로 의미를 판정하지 않는다.
- R3. 검토 모델은 pass/revise/wait/unknown을 판단한다. 중요한 누락은 근거와 함께 개발 Claude에
  자동 피드백한다. 질문·수락 대기는 정상 반환하며 문서가 영향받지 않은 작업은 수정하지 않아도 된다.
- R4. 사용자 턴마다 자동 보완은 최대 두 번이며 매 보완 후 최종 판을 다시 검토한다. 실패·미실행·
  지원하지 않는 입력·크기 초과·검토 중 변경·미해결 누락은 통과시키지 않고 rc2와 근거로 인계한다.
- R5. 모델은 개발 Sonnet/low·검토 Sonnet/medium, 검토자는 도구 없이 별도 컨텍스트에서 실제 근거를 읽는다.
  코드가 문서 의미·승인 상태·절 형식을 판정하지 않는다. 관련 없는 스킬/플러그인을 자동 적용하지 않는다.
- R6. 사용자 전용 위치에 실행 파일과 명령을 설치하고 다른 개인 설정·기존 도구를 덮어쓰지 않는다.
  검토 입력·결과·모델·시간·비용·입력 digest를 프로젝트 밖에 남긴다. 숨겨진 추론은 제외한다.
- R7. 프로젝트 목표와 실제 적용 범위를 기록한다. 직접 claude 호출이나 모든 도구 경로에 적용됐다고
  주장하지 않는다. 기존 GitHub의 사람 승인 원칙은 유지하되 이번에 조직 권한 분리/병합 설정을 구축했다고 하지 않는다.

## Design
종료 hook의 외부 timeout·재귀·미실행에 의존하지 않고 작은 CLI가 개발→독립 검토→자동 resume의
순서를 맡는다. 템플릿이나 문서의 승인 상태기계를 만들지 않는다. 공개 대화와 산출물의 정합성은
독립 모델이 판단하고 HUMAN은 업무 의미·수락을 맡는다. 실행 실패와 의미 불확실은 명시적 인계다.
실제 사용 템플릿 add296d는 유지하며 별도 설치한 팀 진입점에서만 동작한다.

## Acceptance criteria
- AC1 → R1–R3: 설치한 진입점의 실제 Claude 대화에서 독립 검토가 실행되고 수락 참조와 인계가 보존된다.
- AC2 → R2–R4: 실제 누락 기록과 통제된 문서 누락/형식 수정이 검토에서 발견된다. 최소 한 실제 개발
  세션에서 자동 피드백과 resume으로 보완되고 재검토된다. 자연 발생과 주입한 결함을 구분한다.
- AC3 → R3: 문서 변경 불필요·정상 질문·수락 대기 사례는 잘못 보완 루프에 넣지 않는다.
- AC4 → R4–R6: timeout/실패/잘못된 결과/변경된 입력/상한은 통과로 표시하지 않는 기계적 테스트가 있다.
- AC5 → R6–R7: 영구 설치 파일의 판과 실행 증거를 확인하고 사용 템플릿 불변·기존 동작의 회귀를 확인한다.

## Constraints and risks
내부 서비스 팀의 얇은 정책을 유지한다. 매 편집마다 호출하지 않지만 정상 대기를 구분하는 검토도
추가 비용이 든다. 현재 소규모 사슬 범위를 넘는 입력은 조용히 잘라 처리하지 않고 인계할 수 있다.
모델 검토의 무오류나 악의적 우회 방지를 이번 목표로 삼지 않는다. 프로세스 실험은 기존 F02 기준에서
파생하고 실험 코드·원본 대화는 실험 브랜치에 보존한다.

실험 중 설계 개정: low 검토는 현재 spec의 수락 SHA와 plan 자체의 오래된 참조를 반복해서
혼동했다. 같은 입력의 medium 검토가 올바르게 지적하여 검토만 medium으로 조정한다. 높은 모델이나
높은 추론을 기본값으로 올리지 않고 역할 난도에 맞춘다. 이전 low 실패와 비교 입력은 보존한다.
