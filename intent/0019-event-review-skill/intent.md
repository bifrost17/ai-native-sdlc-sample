# Intent: 작업 이벤트에 맞춰 문서를 갱신하고 검토하는 팀 스킬
Status: draft.

## Origin
사용자는 매 응답 뒤 독립 검토를 호출하는 별도 CLI와 스킬·서브에이전트 방식의 차이를 확인한 뒤,
플레이북의 작업 이벤트에 맞춰 스킬을 설계하고 실제 Claude Code 실험과 최종 반영까지 위임했다.

## Problem
현재 팀 CLI는 질문·중간 응답과 실제 완료를 구분하기 전에 검토부터 실행한다. 중요한 spec/plan
누락을 발견하는 방법이 별도 실행 프로그램에 묶여 있고, 보통의 Claude Code 세션에서 설치한 팀
지식으로 활용할 수 없다. 외부 호출 자체가 더 정확한 검토를 보장하는 것도 아니다.

## Goal
계획에서 벗어난 구현·후속 요구/설계 변경에는 필요한 문서 갱신을, 관련 커밋 준비에는 동시 반영을,
완료 보고와 PR 검토에는 현재 합의·문서·실제 변경·검증 근거의 대조를 수행하는 설치 가능한 팀
스킬을 제공한다. 일상적인 자체 확인과 필요할 때의 독립 검토를 구분한다.

## Constraints
- 북극성 V4-11·V7-09·V8-02·V8-09·V10-05를 기준으로 한다. 추가 이벤트는 팀의 구체화로 구분한다.
- 스킬과 네이티브 서브에이전트를 기본 경로로 삼고 기존 CLI는 선택적인 실험 도구로 보존한다.
- 스킬 원본·설치/갱신 안내는 이 리포에 포함한다. 사용 템플릿에는 필수 도구를 내장하지 않는다.
- 문서 의미·상태·절 형식 검사기, 매 응답 검토, 무오류 보장과 과한 승인 절차를 추가하지 않는다.
- 난도·영향·불확실성에 따라 모델과 추론 수준을 선택한다. 중요한 검토는 높은 역량을 사용한다.

## Acceptance direction
Codex가 HUMAN, 실제 Claude Code가 AGENT인 대화형 부분 실험에서 자연스러운 업무 요청으로
스킬 사용·필요한 문서 개정·수락 참조·관련 구현과 계획의 같은 커밋·완료 전 독립 검토를 관측한다.
정상 질문과 문서 영향 없는 작업, 기존 제품 동작과 전체 인계의 회귀도 확인한다. 실패·미관측은
보존하고 수정 후 통과한 범위만 북극성 주석에 반영한다.
