# Intent — 유일한 선택형 템플릿과 도구별 동등한 스킬 제공

Status: draft

## Problem
사용자는 Codex와 Claude Code 사용자를 위한 템플릿을 원한다. 현재 TDD 기본형과 선택형을
별도 유지하고 있고, Claude 작성 스킬의 설치·호출 안내는 Codex보다 간략하다.

## Proposed outcome
TDD 선택형을 유일한 현재 배포판으로 삼고 강제형 소스를 삭제한다. 두 도구에서 같은 작성·팀 스킬,
참고 자료와 검토 기준을 선택 설치·갱신·확인할 수 있게 한다.

## Affected people and systems
템플릿 채택 팀, Codex·Claude Code 사용자, 제작 저장소의 README·카탈로그·작성 도구·검사·CI.

## Constraints
북극성 플레이북이 우선이다. 사람이 개입하고 대체로 가이드를 따르는 수준을 목표로 한다.
TDD는 작업별 선택으로 유지하며 새 승인 단계나 의미 검사기를 만들지 않는다.
과거 실험·리뷰 기록과 기존 사용자 설치·제품 작업은 보존한다. 같은 스킬을 두 도구에 맞춰
전달하되 도구 고유 설정까지 같다고 주장하지 않는다.

## Open questions
없음. 이번 삭제와 두 도구 지원 보완은 사용자가 직접 요청했다.
