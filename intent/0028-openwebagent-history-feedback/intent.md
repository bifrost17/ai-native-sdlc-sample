# Intent — 실사용 이력으로 템플릿의 남은 문제 개선

Status: draft

## Problem
사용자는 openWebAgent에서 이 템플릿을 사용해 30개가 넘는 작업을 진행했다.
맥북과 윈도우에서 작업해 기록이 여러 곳에 나뉘었다. 개별 실험뿐 아니라 실제 개발 이력에서
현재 템플릿의 문제를 찾고 싶다. 최신 문서나 PR 숫자만으로는 어떤 지침이 부족했는지 알기 어렵다.

## Proposed outcome
접근 가능한 모든 개발건의 중요한 사건을 조사한다. 당시 지침, 실행, 사람의 결정과 복구를
현재 배포판 및 미커밋 후보와 구분해 대조한다. 현재도 남은 일반적인 문제만 소수 보완하고,
실제 개발의 전후 비교와 다른 도구의 실행으로 효과와 회귀를 확인한다.

## Affected people and systems
템플릿 제작자, Codex·Claude Code 채택 팀, openWebAgent의 작업·검증·인계 기록.

## Constraints
북극성 플레이북이 우선이다. 대체로 가이드를 잘 따르는 수준을 목표로 한다.
템플릿과 팀 스킬의 역할을 구분하고 에이전트 실수마다 규칙이나 검사기를 추가하지 않는다.
접근 가능한 모든 개발건을 심층 조사하되 동일 사건·자료를 중복 분석하지 않는다.
원격에서 원인이 확인되지 않는 사건에만 필요한 로컬 대화 구간을 보충한다.
제품·운영 환경과 전역 스킬은 변경하지 않는다. 기존 미커밋 작업과 역사 기록을 보존한다.
원문·출처·대상판과 한계를 남기며, 미관측을 실패나 통과로 바꾸지 않는다.

## Open questions
없음. 사용자가 전수 심층 분석, 분석→소수 개선→재실험,
원래 에이전트의 전후 비교와 다른 도구의 전이 확인을 선택하고 실행을 요청했다.
