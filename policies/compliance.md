# 데이터 취급 정책 — 팀 조항 (C)
Owner: 정책 오너. Status: draft — 바닥선(`policies/README.md`).

전제: **사내 임직원이 쓰는 소프트웨어**다 — 외부 고객에게 팔거나 제공하지 않는다. 그래서 조항은 얇다.
외부로 나가는 프로젝트(사외 사용자·외부망 노출·규제 대상)는 그 프로젝트가 **P3 에 추가 규칙을 적는다.**

- **C1** 자격증명(토큰 · 키 · 비밀번호 · 접속 문자열)은 코드 · 설정 · 로그 · 화면 · diff 에 두지 않는다.
- **C2** 임직원 개인정보와 인증 정보는 필요한 자리에만 둔다. 로그 · 오류 메시지 · 감사 이벤트에는 내부 ID 만 남기고, 예외를 통째로 찍지 않는다(요청 본문 · 헤더가 함께 나간다). 무엇이 민감한지는 **P2**.
- **C3** 접근·변경 이력은 누가 · 무엇을 · 언제(UTC)로 남긴다. 보존 기간은 **P2**.

사외로 나가는 데이터·알림이 있으면 그 프로젝트가 **P3** 에 규칙을 적는다(동의 · 통지 · 국외 이전 등) — 팀 조항은 사내를 전제한다.
