# 컴플라이언스 정책 v0
Owner: 정책 오너(이 레포 소유자). Status: draft v0 — 오너 서명 대기(서명 = 개정 PR 머지). 조항 ID 는 스킬·coverage 가 인용하는 고정 키다.
대상: 보험 청구 상태 조회 서비스(고객 포털 · 사정인 · 상담사 경로)와 그 고객 통지.

## PII
- **C1** 주민등록번호·계좌번호·연락처 전체는 어떤 응답·화면·통지에도 싣지 않는다. 필요하면 마스킹(뒤 4자리 등)만.
- **C2** 응답 필드는 허용 목록으로 — 필드를 더할 때 그 근거 조항을 spec 에 적는다.
- **C3** 로그·오류 메시지·audit 이벤트에 PII 를 넣지 않는다(식별자는 청구 번호·내부 ID 만).
## 동의·통지
- **C4** 고객 통지(이메일·SMS)는 수신 동의가 기록된 채널로만. 동의 상태를 확인하지 못하면 보내지 않는다.
- **C5** 통지 본문에는 근거(어느 청구, 어느 상태 변경)와 문의 경로를 적고, 상태 이외의 민감 정보(사유 상세·금액 산정 근거)는 싣지 않는다.
## 보존·감사
- **C6** 조회·통지 이력은 누가(역할·ID) · 무엇을(청구 번호) · 언제(UTC) 로 기록하고 보존 기간은 3년.
- **C7** 제3자(상담사·사정인)의 대리 조회는 본인확인 기록이 있을 때만, 그 기록 ID 를 함께 남긴다.
