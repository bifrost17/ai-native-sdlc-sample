# 사용성 정책 — 팀 조항 (U)
Owner: 정책 오너. Status: draft — 바닥선(`policies/README.md`).

전제: **사내 임직원이 쓰는 소프트웨어**다 — 외부 고객에게 팔거나 제공하지 않는다. 그래서 조항은 얇다.
외부로 나가는 프로젝트(사외 사용자·외부망 노출·규제 대상)는 그 프로젝트가 **P3 에 추가 규칙을 적는다.**

사람이 조작하는 표면(화면 · CLI · 알림)에 걸린다. 사람이 안 보는 배치·API 전용 프로젝트는 **P3** 에 「해당 없음」으로 적는다.

- **U1** 오류 메시지는 셋을 담는다: 무엇이 안 됐는지 · (알 수 있으면) 왜 · 다음에 할 행동. 사내 도구라도 스택 트레이스를 그대로 던지지 않는다 — 동료의 시간이 값이다.
- **U2** 파괴적·비가역 동작(삭제 · 초기화 · 배포 · 되돌릴 수 없는 이관)은 확인 단계와 되돌리는 경로를 함께 둔다. 파괴적 선택을 기본값·기본 포커스로 두지 않는다.
- **U3** 기다리게 할 때는 예상 시간이나 다시 확인할 시점을 적는다.

접근성 기준이 필요한 프로젝트는 **P3** 에 판과 검사 방법을 적는다 — 팀 바닥선에는 두지 않는다.
