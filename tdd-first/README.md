# TDD 기본형

새·변경 동작을 test-first로 개발하는 현재 방식을 보존한 배포판이다. 의미 있는 실패를 관측하고
최소 구현·재검증·필요한 리팩터링을 한다. 이미 만족하는 동작·순수 리팩터링에 RED를 꾸미지 않으며
기존 정책의 중요한 예외·이탈 합의와 근거 기록을 유지한다.

## 채택

1. [project/README.md](project/README.md)를 읽고 `project/`의 **내용**을 별도 제품 저장소 루트로 복사한다.
2. 제품의 [PROJECT-POLICY.md](project/PROJECT-POLICY.md)에 실제 역할·명령·정책을 채운다.
3. 필요하면 이 판의 [팀 스킬](org-skills/README.md)을 선택 설치한다. Claude/OpenCode용 동반 검증자가 포함된다.

`project/`에는 활성 `.claude`/`.opencode` 스킬·훅이 없다. 작성 스킬은 `project/examples/skills/`의
선택 예시다. 기존 사용자 전역 설치를 자동 변경하지 않으며 다른 판의 패키지와 동시에 적용하지 않는다.
한 폴더를 별도 위치로 복사해도 제품 문서와 스킬 패키지가 각각 독립적으로 읽힌다.
