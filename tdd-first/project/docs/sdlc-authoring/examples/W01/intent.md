# Intent: 동료가 자기 신청의 처리 상태를 직접 확인
Author: 합성 포털 업무 오너 W01. Status: draft.

## Problem
직원들이 이미 제출한 신청의 처리 상태를 담당자에게 반복해서 묻고 있다.

## Proposed outcome
사내 포털에서 내가 제출한 신청과 현재 상태를 바로 보고 싶다. 담당자에게 물어보지 않아도
진행 중인지 완료됐는지 알 수 있으면 된다. 기존 신청 폼은 계속 사용할 수 있어야 한다.

## Affected users and systems
신청한 직원, 사내 포털, 기존 요청 API와 저장소. 담당자의 관리 화면은 이번 변경 대상이 아니다.

## Constraints
다른 직원의 신청과 내부 메모를 노출하지 않는다. 기존 로그인/권한·데이터·신청/관리 기능을 유지한다.
조회만 추가하고 새 서비스·계정·알림·상태 변경 기능은 만들지 않는다.
API만 완성된 중간 상태를 전체 기능 공개로 취급하지 않는다. 작은 PR로 통합하며 개발 중 시험할 수 있어야 한다.

## Open questions
- Q1 어떤 신청과 정보를 어떤 순서로 보여줄까?
- Q2 결과가 없거나 조회에 실패하면 어떻게 알리고, 얼마나 자주 갱신할까?
- Q3 개발 중 시험 대상과 일반 공개/중단 담당은 누구인가?

합성 후속 답과 현재 계약은 [context](context.md)에 있다. 이것이 본 예시의 원 요청이며 실제 제품 수락은 아니다.
