# 요구·설계·작업의 추적 규칙

이 번호는 개발건의 문서 집합 안에서 중요한 항목을 찾기 위한 팀 규칙이다.
intent는 요청자의 문제·제안·제약·미결 질문을 산문으로 남긴다. 요구의 정리는 spec에서 시작한다.

| ID | 정의하는 곳·의미 |
|---|---|
| FR01 / NFR01 | spec의 기능 요구 / 품질 요구. intent 문단·답변·정책·현재 계약에서 근거를 연결 |
| AC01 | spec의 관찰할 수 있는 인수 조건. 구현과 독립된 기대와 관련 요구를 연결 |
| SP01 | spec 또는 선언된 설계 정본의 주요 계약·결정·컴포넌트 책임. 관련 요구와 필요한 AC를 참조 |
| T01 | plan 또는 선언된 작업 정본의 맡아서 끝낼 작업. SP/AC·실제 구현 방법·검증·Done·소속 PR을 연결 |

기존 R1/AC1/P1 등의 ID는 계속 유효하다. 새 양식을 적용하려고 과거 번호를 일괄 교체하지 않는다.
T와 PR·Proof 번호는 별개다. 작업·에이전트·커밋·PR은 서로 일대일이 아니며 작은 계획은 짧게 쓸 수 있다.

## 범위와 수명

- ID는 같은 개발건의 문서 집합 안에서 유일하다. 다른 개발건은 문서 경로+ID로 구분한다.
- 같은 요구·결정·작업을 개정하거나 옮겨도 ID를 유지한다. 판은 Git과 기존 Upstream이 기록한다.
- 별개 항목이나 분할한 항목에는 새 ID를 부여하고 기존 ID와 대체/분할 관계를 남긴다.
  폐기한 ID는 재사용하지 않는다. 제거 이유와 후속 참조는 기존 문서/변경 기록에서 찾게 한다.
- 각 ID는 한 정본에서만 정의한다. spec의 설계 색인은 SP·소유 경로·필수 읽기를 안내하고,
  상세 계약과 요구 관계는 소유 정본에 둔다. plan의 Files/Proof는 작업과 근거의 색인이다.
- 여러 SP가 한 요구를 나누거나 한 SP가 여러 요구를 충족할 수 있다. T도 여러 SP를 구현할 수 있다.
  구현하지 않는 보존 계약은 기존 동작의 근거로, 후속 범위는 담당 작업/인도로 연결한다.
  역방향 조회는 같은 참조를 검색해 확인하며 양쪽에 같은 관계표를 중복 유지하지 않는다.

모든 문장·클래스·메서드에 번호를 붙이거나 별도 전역 장부를 만들지 않는다.
새 중요한 동작·구조는 현재 설계 또는 허가된 개정에 근거해야 하며 작업 메모만으로 설계를 바꾸지 않는다.

## 참조와 판

`design/storage.md의 SP02`처럼 경로+ID를 쓴다. 클릭 링크가 필요하면 실제 제목이나 명시한
anchor를 연결한다. Markdown 표에 `SP02`를 적었다고 `#sp02` anchor가 생기지는 않는다.
상세 문서를 이동하면 진입점과 소비자의 경로도 고친다.

Upstream은 실제 읽은 상류 판을 가리킨다. 현재 허가된 수정과 이전 수락 판을 구분하고,
같은 커밋의 spec/plan 개정에는 [실행 상세의 현재 변경 표기](../../examples/skills/plan/references/execution-depth.md)를
쓴다. 미래 SHA나 수락 표기를 만들지 않는다. ID가 유효해도 연결된 내용이 낡을 수 있으므로 영향과 기대를 대조한다.

## 작은 연결 예

다음은 형식 설명이며 실행 근거나 제품 요구가 아니다.

spec의 FR01은 “담당자 이름으로 목록을 좁힌다”를 요청 문단에 연결하고, NFR01은 “저장 형식을 유지한다”를
확인한 호환 정책에 연결한다. AC01은 일치/불일치 입력의 출력 기대를 정의한다.
같은 spec의 SP01은 FR01·NFR01을 참조하며, 기존 읽기 이후 출력 직전에 필터를 적용하고 저장을 바꾸지 않기로 결정한다.

plan의 T01은 `spec.md의 SP01/AC01`을 읽고, 확인한 목록 함수의 읽기→출력 사이에 조건을 넣는 방법,
해당 입력 시험과 저장 불변 확인, 완료 시 관찰할 결과를 적는다. 소속 PR은 “담당자 필터”이고 Proof P1은
T01의 시험을 가리킨다. 시험 순서는 적용한 배포판을 따른다. 실제 사례는 기존 R/AC를 보존한
[F01](examples/F01/spec.md)과 정본을 나눈 [M01](examples/M01/spec.md)을 함께 읽는다.
