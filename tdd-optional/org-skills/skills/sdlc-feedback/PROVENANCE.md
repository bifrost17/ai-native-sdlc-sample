## 선택형 실행 지침 보완 — 2026-09-12 / 0.1.1

작업에 맞는 브라우저·직접 관찰, 탐색의 학습 목표와 제품 편입 시 AC·회귀·통합 검증을 구분했다.
완료 전 새 문맥 검토는 이 팀 스킬의 기존 규칙으로 유지하며, 새 문맥이 기대의 독립성이나 정답을
보장하지 않음을 명시했다. 기대 기준을 먼저 읽는 구현 검토는 구현 비노출 테스트 생성과 다르다.
위 기본형 이력의 모든 변경·리뷰 결함 test-first 연결을 선택형의 현재 의무로 읽지 않는다.
플레이북의 버그 test-first와 수정 중 시험 동결(제작본 주석 V8-07·V8-10·V8-12)은 선택형에서 조정한 팀 정책이다.
독립 기대·검증 무결성·회귀 보호와 실제 프로젝트의 시험 보호 통제는 유지한다.
지침·manifest·어댑터의 정적 확인은 새 판의 자연 호출·위임·실제 제품 검증 증거가 아니다.
