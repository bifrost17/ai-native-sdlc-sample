# 간결한 선택형 작성 예시

이 폴더는 이전의 간결한 사례에 작업별 방식·이유를 명시한 선택형 교육 사본이다. feature/two-pr는 동작별 구현 후 테스트,
bug는 명시 요청과 재현 특성에 맞춘 TDD, migration은 혼합을 보여준다. 제품 계약과 과거 입력 판은 유지한다.
현행 양식을 채우는 구체적 깊이와 필수 입력은 [작성 예시 세트](../../../../docs/sdlc-authoring/README.md)를 참고한다.
two-pr는 각 PR이 독립적으로 쓸 수 있는 기능이며, F03은 두 PR이 하나의 공개 단위인 경우다.

- [기존 시험을 활용한 리팩터링](refactor-existing-tests.md): 동작 변경이 없는 작은 구조 정리와 기존 검증의 범위·한계.
- [폐기할 UI 탐색](disposable-ui-exploration.md): 모호한 UI 결정을 위한 직접 관찰과 탐색 성공·제품 완료의 구분.

두 예시는 특정 제품의 수락·실행 기록이 없는 plan-only 합성 자료다. 실제 적용에서는 현재 제품의 spec 판,
코드·시험 경로와 명령을 확인해 바꾼다.
