# 제품 변경의 기록

현재 진행한 제품 변경은 없다. 첫 변경은 `0001-<slug>/`에서 시작하고, 다음 번호는 기존 변경을 확인해
정한다. 동시 작업이면 시작을 조율하는 사람이 겹치지 않게 번호를 정한다.

각 폴더에 `intent.md`, `spec.md`, `plan.md`를 [개발 절차](../docs/PROCESS.md)에 따라 단계별로 만든다.
[templates/](../templates/)는 빈 양식이며 실제 요구사항이나 승인 기록이 아니다.

PR에는 해당 변경 폴더와 인계할 근거를 연결한다. 제품 개발과 전체 절차 실험은 각자의 통합 대상과
출발 커밋을 명시하고, 다른 작업의 문서를 자기 작업의 승인 근거로 사용하지 않는다.
